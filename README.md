### How do you make a GronnFalk instance?

#### To make a GronnFalk Instance follow these steps:

1. Fork the <a href="https://github.com/LiamProsser77/gronnfalk">GronnFalk Repository</a>

2. Go to Render or Railway or another service and sign up or login

3. Go to your dashboard and select "New" and create a web service

4. Render or Railway will make the website for you

5. Your GronnFalk instance is online!
