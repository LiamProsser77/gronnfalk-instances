<h2>Do you want your Instance of GronnFalk on this List?</h2>

<ol>
  <li>First, create an issue on this repository.</li>

  <li>
    Second, name your issue in this format:
    <code>Add (Your URL here)</code>
  </li>

  <li>
    Next, copy and complete the instance template below.
  </li>

  <li>
    Submit the completed template in your issue.
  </li>

  <li>
    GronnFalk Maintainers will review the submission when they have time.
  </li>
</ol>
